# Toolsbuild

## Description

tools builds is a compilation of websites focused on technology and aimed at developers.

1. Clone the source code to your device
```sh
git clone https://github.com/DylanZM/ToolsBuild.git
```

2. Install the project's dependencies
```sh
npm install
```

3. Start the development server on `localhost:4321`
```sh
npm run dev
```

4. Build the site to `/dist`
```sh
npm run build
```
